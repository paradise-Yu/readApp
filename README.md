# readApp

Android 本地阅读器应用

## 功能

### 书架与书库

- 支持 TXT、PDF、EPUB 格式
- 通过 SAF 添加本地文件夹，自动扫描入库书籍（支持子目录递归）
- 书架网格/列表切换，按最近阅读/书名/添加时间排序，下拉刷新
- 本地搜索：按书名、作者搜索 + 标签筛选 + TXT 全文搜索
- 书籍详情：星级评分、标签管理（公共标签库，带颜色）

### 阅读体验（TXT）

- 字体大小调节、五种护眼阅读背景
- 上下滚动 / 左右翻页两种阅读模式
- 章节目录：正则识别"第X章/回/节"等常见格式，点击跳转
- 书签：一键添加、跳转、删除
- 阅读位置记忆：精确到段内像素偏移，阅读中 2 秒自动落库，杀进程不丢进度
- 自动字符集识别（UTF-8 / GBK 等）

### 隐私与隐身

- 文件夹可设置密码隐藏：密码以明文存于文件夹内的 `密码.txt`，删除该文件即解除隐藏
- 隐身模式：输入密码进入，仅显示对应文件夹内容，一键退出

### 其他

- Material 3 动态主题

## 技术栈

- Kotlin + Jetpack Compose
- MVVM + Clean Architecture
- Room 数据库
- Hilt 依赖注入
- AndroidPdfViewer
- Navigation Compose

## 构建

```bash
./gradlew assembleDebug
```
