# readApp

Android 本地阅读器应用

## 功能

### 书架与书库

- 支持 TXT、PDF、EPUB 格式
- 通过 SAF 添加本地文件夹，自动扫描入库书籍（支持子目录递归）
- 书架网格/列表切换，按最近阅读/书名/添加时间排序，下拉刷新
- **列表模式显示文件大小**
- **书架列表缓存**：避免重复查询和排序
- **共享内容缓存（FolderContentCache）**：书架与文件夹管理共用同一数据源，密码/书籍/反向索引一次构建、多处读取
- **预计算可见列表**：普通模式文件夹、全部书籍视图在缓存构建时预计算，UI 直接读取无需过滤
- **"全部书籍"过滤优化**：隐藏加密文件夹的书 + 孤立书（folderId 不存在）
- 本地搜索：按书名、作者搜索 + 标签筛选 + TXT 全文搜索
- 书籍详情：星级评分、标签管理（公共标签库，带颜色）
- **系统文本文件打开方式**：在任意应用（如 QQ）中选择文本文件"用本应用打开"，自动按来源应用创建文件夹（如 `QQ` 文件夹）并复制文件后导入书库
- **文件夹管理**：只显示文件夹名，不显示全路径

### 阅读体验（TXT）

- 字体大小调节、五种护眼阅读背景
- 上下滚动 / 左右翻页两种阅读模式
- **长按选中文字复制**：长按即可选中文字，系统弹出复制/全选菜单
- **章节目录缓存**：首次解析后存入内存，后续打开直接读取，无需重复解析
- 章节目录：正则识别"第X章/回/节"等常见格式，点击跳转
- 书签：一键添加、跳转、删除
- **手动插入目录**：底栏点击按钮在当前阅读位置插入章节标记，自动重建目录并持久化到文件
- 阅读位置记忆：精确到段内像素偏移，阅读中 2 秒自动落库，杀进程不丢进度
- 自动字符集识别（UTF-8 / GBK 等）

### 隐私与隐身

- 文件夹可设置密码隐藏：密码以明文存于文件夹内的 `密码.txt`，删除该文件即解除隐藏
- 隐身模式：输入密码进入，仅显示对应文件夹内容，一键退出

### 其他

- Material 3 动态主题

- Room 数据库
- Hilt 依赖注入
- AndroidPdfViewer
- Navigation Compose
